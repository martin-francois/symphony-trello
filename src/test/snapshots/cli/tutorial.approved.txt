What GitHub pull request integration adds
Without GitHub integration, Symphony still runs the Trello and Codex loop for card-based work.
Setup adds GitHub-specific lists such as "Merging" only when GitHub integration is configured.
With it, Symphony can create and update pull requests, link them on Trello cards, and process
feedback from pull requests and Trello comments. "Merging" then means "do final checks and merge
this PR if safe" before Symphony moves the finished card to "Done".
To add GitHub integration later, run:
  symphony-trello setup-local configure-github
